# 🛒 Retail Sales Analysis

An end-to-end Retail Sales Analytics project developed using Python and Power BI.

The objective of this project is to analyze historical retail sales data, identify business patterns, perform exploratory data analysis (EDA), and build an interactive dashboard to support business decision-making.

---

# Project Objectives

- Understand the dataset.
- Clean and validate the data.
- Perform feature engineering.
- Conduct Exploratory Data Analysis (EDA).
- Build an interactive Power BI dashboard.
- Generate business insights.

---

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI

---

# Business Insights

Some of the main findings include:

- Technology generated the highest sales.
- The West region produced the highest profit.
- High discounts significantly reduced profitability.
- A small group of customers generated a large share of total sales.
- Sales increased during the last quarter of the year.
